## 🎯 Project Overview

This portfolio serves as a central operational dossier showcasing software engineering projects, technical skill matrices, academic milestones, and encrypted communication channels. The design prioritizes visual immersion, clean responsive layouts, and interactive 3D canvas rendering without heavy external dependencies.

---

## ⚡ Key Highlights & Features

### 🖥️ Tactical HUD & Theming
- **NERV Design System**: Void Black (`#080808`), MAGI Amber/Orange (`#FF4500`), Sync Green (`#00FF66`), and Absolute Red (`#FF0033`).
- **Geometric Panels**: Angular HUD clip-paths, tactical bracket borders, and monospaced diagnostic headers.
- **CRT Scanlines & HUD Controls**: Toggleable retro scanline filter, dark/light theme switching, and live UTC system clock.
- **Dual-Language i18n**: Real-time switching between **English (EN)** and **Brazilian Portuguese (PT-BR)** with full persistence.

### 🌌 Interactive 3D Canvas Background
- **Ramiel (5th Angel)**: Translucent cobalt-cyan 3D octahedron that morphs, splits facets, and fires a concentrated particle cannon laser targeting the cursor on hover.
- **Spear of Longinus (Lança de Longinus)**: Canonical double-helix DNA shaft with dual eyelet loops, barbed shoulder wings, and twin needle tines rotating in full 3D unison impaled into the moon crater.
- **AT-Field Impact Waves**: Mouse-following octagonal ripple matrices and expanding click-impact shield rings.

### 🚨 Secret Easter Eggs
- **Konami Code Protocol**: Type `↑` `↑` `↓` `↓` `←` `→` `←` `→` `B` `A` on any screen to trigger a full-screen **"ANGEL ATTACK // PATTERN BLUE"** tactical emergency containment alert.
- **Secret NERV Logo Trigger**: Click the header NERV badge 5 consecutive times to activate emergency protocol.

### 📂 Operational Modules
- **Hero & Pilot Status**: Live-fluctuating A-10 Synchronicity Ratio gauge and clearance status.
- **MAGI Supercomputer System**: Diagnostic 3-core consensus visualizer (Melchior-1, Balthasar-2, Caspar-3).
- **Project Dossier Grid**: Classified project cards with clearance levels, tech tags, and detailed modal views.
- **Skills Matrix**: Core synchronization bars categorized by subsystem (Frontend, Backend, Database, Cloud).
- **Mission Log Timeline**: Academic and career milestones formatted as chronological mission logs.
- **Direct Transmission Frequency**: Encrypted communication terminal with direct transmission form and authenticated channels.
